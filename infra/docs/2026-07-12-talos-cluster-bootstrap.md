# Talos Cluster Bootstrap — TuringPi 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a 3-node Talos Linux cluster on TuringPi 2 (RK1/RK3588) with Cilium CNI, Spegel registry mirrors, and TinyCA root CA trust — fully automated via `just` recipes.

**Architecture:** talhelper renders machine configs from a single `talconfig.yaml` + patch files. A `just talos-generate` recipe decrypts the TinyCA root CA cert from SOPS and injects it into a generated patch at runtime. Bootstrap runs through `just` recipes: generate → apply → bootstrap → kubeconfig → cilium.

**Tech Stack:** Talos Linux (arm64/RK1 overlay), talhelper, talosctl, Cilium (Helm), kubectl, sops, step CLI, just

## Global Constraints

- All 3 nodes: RK1 (RK3588), arm64, TuringPi 2 slots 1/3/4
- VLAN 30: `192.168.30.0/24`, gateway `192.168.30.1`
- Node IPs: `.11` (turingpi-1), `.13` (turingpi-3), `.14` (turingpi-4)
- VIP: `192.168.30.99` (Talos L2 VIP, below DHCP range .100–.200)
- All nodes are `controlPlane` type, `allowSchedulingOnControlPlanes: true`
- `cniConfig.name: none` — Cilium owns CNI
- `cluster.proxy.disabled: true` — Cilium replaces kube-proxy
- Root CA cert never stored in plaintext — extracted from SOPS at generate time
- `secretboxEncryptionSecret` is user-generated (`openssl rand -base64 32`), stored in SOPS-encrypted `talsecret.sops.yaml`
- `patches/custom-ca.yaml`, `clusterconfig/`, `talosconfig`, and `talsecret.yaml` (plaintext) are gitignored
- `talsecret.sops.yaml` (encrypted) is committed to the repo
- Homelab repo assumed at `../homelab` relative to this repo root
- SOPS age key at `../homelab/key.txt.secret`

## Task 2b: Generate and Encrypt Cluster Secrets (`talsecret.sops.yaml`)

**Files:**
- Create: `infra/talos/talsecret.sops.yaml` (SOPS-encrypted, committed)

**Interfaces:**
- Consumes: age public key from `../homelab/key.txt.secret`
- Produces: `talsecret.sops.yaml` — passed to `talhelper genconfig --secret-file` at generate time

- [ ] **Step 1: Generate the base secrets file**

  Run from `infra/talos/`:
  ```bash
  cd infra/talos
  talhelper gensecret > talsecret.yaml
  ```
  This creates `talsecret.yaml` with auto-generated cluster CA key pairs, bootstrap token, and a random `secretboxEncryptionSecret`.

- [ ] **Step 2: Replace the auto-generated `secretboxEncryptionSecret` with your own**

  Generate a 32-byte key:
  ```bash
  openssl rand -base64 32
  # Example output: 4Hv8KqZ2mXnPwRtYcLsJdNfUeOgAbCvE1hIkMjQp3r0=
  ```

  Open `talsecret.yaml` and replace the value of `secretboxEncryptionSecret` with your generated key. The field looks like:
  ```yaml
  secretboxEncryptionSecret: <replace-this-value>
  ```

- [ ] **Step 3: Get your age public key**

  ```bash
  age-keygen -y ../homelab/key.txt.secret
  # Prints: age1xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
  ```

- [ ] **Step 4: Encrypt with SOPS**

  ```bash
  SOPS_AGE_KEY_FILE=../homelab/key.txt.secret \
    sops --encrypt \
    --age $(age-keygen -y ../homelab/key.txt.secret) \
    talsecret.yaml > talsecret.sops.yaml
  ```

- [ ] **Step 5: Verify the encrypted file decrypts correctly**

  ```bash
  SOPS_AGE_KEY_FILE=../homelab/key.txt.secret \
    sops --decrypt talsecret.sops.yaml | grep secretboxEncryptionSecret
  # Expected: secretboxEncryptionSecret: <your key>
  ```

- [ ] **Step 6: Shred the plaintext file**

  ```bash
  shred -uzv talsecret.yaml
  ```

- [ ] **Step 7: Commit the encrypted secrets file**

  ```bash
  git add infra/talos/talsecret.sops.yaml
  git commit -m "feat(talos): add SOPS-encrypted cluster secrets"
  ```

- Produces: patch applied to every node's machine config — sysctls, kernel modules, registry mirrors, proxy disabled

- [ ] **Step 1: Create `infra/talos/patches/all-nodes.yaml`**

  ```yaml
  ---
  # Kernel modules required by Cilium and Istio
  machine:
    kernel:
      modules:
        - name: br_netfilter
        - name: ip_tables
        - name: ip6_tables
        - name: nf_conntrack

    # Sysctl tuning for Cilium eBPF and Istio sidecar traffic volumes
    sysctls:
      fs.inotify.max_user_watches: "524288"
      fs.inotify.max_user_instances: "512"
      net.core.rmem_max: "134217728"
      net.core.wmem_max: "134217728"
      net.core.netdev_max_backlog: "5000"

    # Registry mirror chain: Spegel (P2P) → Zot (in-cluster cache) → upstream
    # During bootstrap, Spegel and Zot don't exist yet — containerd falls through to upstream.
    # After bootstrap, all pulls are served from cache.
    registries:
      mirrors:
        docker.io:
          endpoints:
            - http://localhost:5001
            - http://zot.registry.svc.cluster.local:5000
            - https://registry-1.docker.io
        ghcr.io:
          endpoints:
            - http://localhost:5001
            - http://zot.registry.svc.cluster.local:5000
            - https://ghcr.io
        quay.io:
          endpoints:
            - http://localhost:5001
            - http://zot.registry.svc.cluster.local:5000
            - https://quay.io
        registry.k8s.io:
          endpoints:
            - http://localhost:5001
            - http://zot.registry.svc.cluster.local:5000
            - https://registry.k8s.io

  # Disable kube-proxy — Cilium replaces it via eBPF
  cluster:
    proxy:
      disabled: true
  ```

## Task 6: Write `just/talos.just`

**Files:**
- Create: `just/talos.just`

**Interfaces:**
- Consumes: `infra/talos/talconfig.yaml`, `infra/talos/patches/`, `../homelab/infra/tinyca/pki/pki-export/pki-export.sops.yaml`
- Produces: all `just talos-*` recipes

- [ ] **Step 1: Create `just/talos.just`**

  ```just
  # ── Talos Cluster Management — TuringPi 2 ─────────────────────────────────

  TALOS_DIR      := justfile_directory() + "/infra/talos"
  HOMELAB_DIR    := justfile_directory() + "/../homelab"
  SOPS_FILE      := HOMELAB_DIR + "/infra/tinyca/pki/pki-export/pki-export.sops.yaml"
  AGE_KEY        := HOMELAB_DIR + "/key.txt.secret"
  TALOSCONFIG    := TALOS_DIR + "/talosconfig"
  CP_NODES       := "192.168.30.11,192.168.30.13,192.168.30.14"
  BOOTSTRAP_NODE := "192.168.30.11"
  VIP            := "192.168.30.99"

  # Generate Talos machine configs (decrypts TinyCA root CA + cluster secrets from SOPS, then runs talhelper)
  talos-generate:
      #!/usr/bin/env bash
      set -euo pipefail
      TALSECRET_PLAIN="/tmp/talsecret-$$.yaml"
      trap 'rm -f "$TALSECRET_PLAIN"' EXIT

      echo "Decrypting cluster secrets from SOPS..."
      SOPS_AGE_KEY_FILE="{{AGE_KEY}}" sops --decrypt \
        "{{TALOS_DIR}}/talsecret.sops.yaml" > "$TALSECRET_PLAIN"

      echo "Extracting TinyCA root CA from SOPS..."
      ROOT_CA=$(SOPS_AGE_KEY_FILE="{{AGE_KEY}}" sops --decrypt \
        --extract '["root_ca_crt"]' "{{SOPS_FILE}}")

      echo "Writing patches/custom-ca.yaml..."
      cat > "{{TALOS_DIR}}/patches/custom-ca.yaml" <<EOF
  machine:
    files:
      - content: |
  $(echo "$ROOT_CA" | sed 's/^/        /')
        path: /etc/ssl/certs/homelab-root-ca.crt
        permissions: 0644
        op: create
  EOF

      echo "Running talhelper genconfig..."
      cd "{{TALOS_DIR}}" && talhelper genconfig \
        --secret-file "$TALSECRET_PLAIN" \
        --out-dir clusterconfig

      echo "Done. Configs written to infra/talos/clusterconfig/"

  # Apply machine configs to all nodes (nodes must be in Talos maintenance mode)
  talos-apply:
      #!/usr/bin/env bash
      set -euo pipefail
      declare -A NODES=(
        [turingpi-1]="192.168.30.11"
        [turingpi-3]="192.168.30.13"
        [turingpi-4]="192.168.30.14"
      )
      for hostname in turingpi-1 turingpi-3 turingpi-4; do
        ip="${NODES[$hostname]}"
        cfg="{{TALOS_DIR}}/clusterconfig/turingpi-${hostname}.yaml"
        echo "Applying config to $hostname ($ip)..."
        talosctl apply-config --insecure --nodes "$ip" --file "$cfg"
      done
      echo "Configs applied. Nodes are rebooting — wait ~2 min before bootstrapping."

  # Bootstrap etcd on the first control plane node (run once per cluster lifetime)
  talos-bootstrap:
      #!/usr/bin/env bash
      set -euo pipefail
      echo "Waiting for {{BOOTSTRAP_NODE}} to be reachable..."
      talosctl --talosconfig "{{TALOSCONFIG}}" \
        -n {{BOOTSTRAP_NODE}} \
        health --wait-timeout 10m --server=false
      echo "Bootstrapping etcd on {{BOOTSTRAP_NODE}}..."
      talosctl --talosconfig "{{TALOSCONFIG}}" \
        -n {{BOOTSTRAP_NODE}} \
        bootstrap
      echo "Bootstrap initiated. etcd quorum is forming across all 3 nodes."

  # Fetch kubeconfig and merge into ~/.kube/config
  talos-kubeconfig:
      talosctl --talosconfig "{{TALOSCONFIG}}" \
        -n {{VIP}} \
        kubeconfig --merge
      @echo "kubeconfig merged. Context: $(kubectl config current-context)"

  # Install Cilium CNI (run immediately after talos-kubeconfig — nodes won't Ready without it)
  talos-cilium:
      #!/usr/bin/env bash
      set -euo pipefail
      helm repo add cilium https://helm.cilium.io/ 2>/dev/null || true
      helm repo update cilium
      helm upgrade --install cilium cilium/cilium \
        --namespace kube-system \
        --wait --timeout 5m \
        --set kubeProxyReplacement=true \
        --set k8sServiceHost={{VIP}} \
        --set k8sServicePort=6443 \
        --set ipam.mode=kubernetes \
        --set routingMode=native \
        --set autoDirectNodeRoutes=true \
        --set ipv4NativeRoutingCIDR=10.244.0.0/16 \
        --set bpf.masquerade=true \
        --set operator.replicas=2 \
        --set hubble.enabled=true \
        --set hubble.relay.enabled=true \
        --set l7Proxy=false
      echo "Cilium installed."
      kubectl get nodes -o wide

  # Check cluster health (Talos + Kubernetes + etcd)
  talos-health:
      #!/usr/bin/env bash
      set -euo pipefail
      echo "=== Talos node health ==="
      talosctl --talosconfig "{{TALOSCONFIG}}" \
        -n {{CP_NODES}} health --server=false
      echo ""
      echo "=== Kubernetes nodes ==="
      kubectl get nodes -o wide
      echo ""
      echo "=== etcd members ==="
      talosctl --talosconfig "{{TALOSCONFIG}}" \
        -n {{BOOTSTRAP_NODE}} etcd members

  # Rolling Talos upgrade (usage: just talos-upgrade v1.9.5)
  talos-upgrade version:
      #!/usr/bin/env bash
      set -euo pipefail
      SCHEMATIC_ID=$(grep talosImageURL "{{TALOS_DIR}}/talconfig.yaml" | \
        head -1 | sed 's|.*factory.talos.dev/installer/||' | tr -d '"')
      IMAGE="factory.talos.dev/installer/${SCHEMATIC_ID}:{{version}}"
      echo "Upgrading all nodes to {{version}} (image: $IMAGE)"
      for NODE in 192.168.30.11 192.168.30.13 192.168.30.14; do
        echo "Upgrading $NODE..."
        talosctl --talosconfig "{{TALOSCONFIG}}" \
          -n "$NODE" upgrade --image "$IMAGE" --wait
        echo "$NODE done."
      done

  # Hard reset all nodes — DESTRUCTIVE, requires 'yes' confirmation
  talos-reset:
      #!/usr/bin/env bash
      set -euo pipefail
      echo "WARNING: This wipes all 3 nodes. All cluster data will be lost."
      echo -n "Type 'yes' to confirm: "
      read -r CONFIRM
      [[ "$CONFIRM" == "yes" ]] || { echo "Aborted."; exit 1; }
      for NODE in 192.168.30.11 192.168.30.13 192.168.30.14; do
        echo "Resetting $NODE..."
        talosctl --talosconfig "{{TALOSCONFIG}}" \
          -n "$NODE" reset --graceful=false --wait=false 2>/dev/null || true
      done
      echo "Reset sent to all nodes. They will reboot into maintenance mode."
      echo "Run before re-bootstrapping:"
      echo "  rm -rf infra/talos/clusterconfig infra/talos/talosconfig"
  ```
