# Talos Linux
----

Setup:
1. Download latest firmware (https://firmware.turingpi.com/turing-rk1/talos/)[https://firmware.turingpi.com/turing-rk1/talos/]
2. Use the BMC UI to flash the nodes (https://turingpi/)[https://turingpi/]
3. Follow the officail Talos docs [https://www.talos.dev/v1.10/talos-guides/install/single-board-computers/turing_rk1/#booting-from-emmc](https://www.talos.dev/v1.10/talos-guides/install/single-board-computers/turing_rk1/#booting-from-emmc)
